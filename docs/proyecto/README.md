## Secciones Excluidas (N/A)
Las siguientes secciones del estándar han sido marcadas como No Aplicables, de acuerdo a la naturaleza de la solución:
*   **4.3 Landing Page:** Yacco es un ERP interno B2B para la operativa diaria. No requiere un portal público de marketing o adquisición de usuarios.
*   **4.4 / 4.5 Mobile iOS & Android:** El acceso en campo (choferes) se realiza mediante una Web Responsiva (PWA). No se desarrollarán aplicaciones nativas para reducir fricción de despliegue.
*   **8.3.3.2 / 8.3.3.4 Landing & Native Evidence:** Se omiten en la evidencia del experimento por la decisión arquitectónica (ERP web).
